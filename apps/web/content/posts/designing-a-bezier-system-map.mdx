Bezier curves are useful when a connection needs direction without looking mechanical. Two endpoints define the relationship; the control points define its character.

## Move the control points

The endpoints remain fixed while the slider moves both control points vertically. The rendered SVG is meaningful before hydration, and the explanation remains available if JavaScript is disabled.

<BezierPlayground />

## What this changes in a system map

A shallow curve reads as a direct relationship. A larger bend creates room for labels, avoids nearby nodes, and gives the connection a stronger visual rhythm.

The useful abstraction is not the curve itself. It is the small set of constraints that lets many curves remain legible as the map grows.
