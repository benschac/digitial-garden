# Social brand assets

Downloaded from the official brand kits on October 8, 2026. Preserve the
original artwork, proportions, and approved black color; do not add effects.

- `bluesky.svg`: official black butterfly from
  https://bsky.social/about/brand-assets/butterfly/bluesky_media_kit_logo_transparent_4.svg
  — guidelines: https://bsky.social/about/support/branding
  explicitly allow the butterfly as a social icon linking to a profile.
- `twitter.svg`: original black Twitter bird, extracted unchanged from
  https://about.x.com/content/dam/about-twitter/en/brand-toolkit/downloads/twitter-logo-01282021.zip
  (`Twitter logo/SVG/Logo black.svg`). This is legacy Twitter branding,
  chosen intentionally instead of the X mark.
  Guidelines: https://about.x.com/content/dam/about-twitter/en/brand-toolkit/downloads/twitter-external-brand-guidelines-01272021.pdf
  Current X toolkit: https://about.x.com/en/who-we-are/brand-toolkit?web=1

The homepage renders both at 24px inside 44px minimum link targets, with
accessible platform names and the profile destinations supplied by the owner.
