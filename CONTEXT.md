# Personal Knowledge Library

The personal knowledge library organizes saved references for later discovery and selective publication on the site.

## Language

**Resource**:
A saved external reference with provenance, descriptive metadata, and publication state.
_Avoid_: Link, bookmark, item

**Resource Type**:
The medium of a resource, such as a book, article, tweet, video, or repository. It describes format rather than subject.
_Avoid_: Category, topic

**Topic**:
A canonical subject shared across resource types, such as TypeScript, Design, or Animation. A resource may belong to several topics.
_Avoid_: Tag, category, resource type

**Draft Resource**:
A resource retained in the library but excluded from the public site pending review.
_Avoid_: Private resource, unpublished link

**Published Resource**:
A resource selected for inclusion on the public resources page.
_Avoid_: Approved link, live bookmark
